# Практика 11. Краткий гид по защите

## Что здесь делалось

В работе подбиралось **оптимальное число кластеров** для набора `Hepta`.

Хотя по заданию достаточно выбрать любые два приема оценки, в ноутбуке использованы **все четыре**:

1. метод локтя;
2. кросс-валидация;
3. силуэтный коэффициент;
4. визуализация матрицы схожести.

В качестве базового алгоритма использовался `k-Means`, а число кластеров перебиралось в диапазоне `k = 3..9`.

## Зачем это делалось

Смысл практики — показать, что выбор числа кластеров не должен опираться на один-единственный критерий.
Разные методы смотрят на качество разбиения с разных сторон:

1. локоть — через внутрикластерную компактность;
2. кросс-валидация — через устойчивость на подвыборках;
3. силуэт — через баланс компактности и разделимости;
4. матрица схожести — через визуальную блочную структуру.

## Как устроена работа

В работе использовался тот же `Hepta`, что и в практике 8, потому что у него хорошо выражена эталонная
семикластерная структура.

Перед экспериментами признаки стандартизовались. Далее для каждого `k` из интервала `3..9` вычислялись:

1. `inertia` для метода локтя;
2. средняя валидационная `inertia` для кросс-валидации;
3. силуэтный коэффициент;
4. матрицы схожести для `k = 6`, `k = 7`, `k = 8`.

## На что смотреть при защите

Главные места в ноутбуке:

1. раздел `5.1`: метод локтя;
2. раздел `5.2`: кросс-валидация;
3. раздел `5.3`: силуэтный коэффициент;
4. раздел `5.4`: матрицы схожести.

Ключевые результаты:

1. по локтю излом кривой `inertia` приходится на `k = 7`;
2. по кросс-валидации после `k = 7` улучшение качества становится гораздо менее существенным;
3. максимум силуэтного коэффициента достигается при `k = 7` и равен `0.7021`;
4. по матрице схожести видно, что при `k = 6` происходит слияние блоков, а при `k = 8` — искусственное расщепление одного из блоков.

Главный итог: все четыре приема согласованно указывают на `k = 7`.

## Возможные вопросы преподавателя

**Что такое качество кластеризации?**  
Это степень того, насколько полученное разбиение соответствует внутренней структуре данных.

**Что такое внутренние критерии качества?**  
Это критерии, которые оценивают кластеризацию без использования внешних истинных меток.

**В чем идея метода локтя?**  
Найти такое `k`, после которого уменьшение `inertia` перестает быть резко выраженным.

**Что показывает `inertia`?**  
Это сумма квадратов расстояний от точек до центров своих кластеров; она характеризует компактность кластеров.

**Зачем нужна кросс-валидация в кластеризации?**  
Чтобы понять, насколько устойчиво выбранное число кластеров переносится на другие части выборки.

**Почему в работе используется 5-блочная кросс-валидация?**  
Это стандартный компромисс между устойчивостью оценки и размером обучающей выборки.

**Что показывает силуэтный коэффициент?**  
Он показывает, насколько объект ближе к своему кластеру, чем к соседнему.

**Почему максимум силуэта при `k = 7` важен?**  
Потому что это означает лучший баланс между компактностью кластеров и их разделимостью.

**Что показывает матрица схожести?**  
Она показывает, насколько четко объекты внутри одного кластера похожи друг на друга и насколько отделены разные кластеры.

**Почему в матрице схожести сравнивались именно `k = 6`, `k = 7` и `k = 8`?**  
Потому что это соседние значения вокруг предполагаемого оптимума, и на них лучше всего видны эффекты недоразбиения и переразбиения.

**Почему выбран именно `k-Means` как базовый алгоритм?**  
Потому что в практике 8 он уже использовался на этом же наборе, и оценка качества здесь привязана к той же постановке.

**Что делать, если разные критерии дают разное `k`?**  
Тогда нужно искать компромисс, анализировать данные визуально и понимать, какой критерий лучше соответствует задаче.

**Какой главный смысл практики?**  
Показать, что оптимальное число кластеров нужно обосновывать несколькими независимыми критериями, а не выбирать по одному графику.
